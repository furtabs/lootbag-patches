# LootBags (1.21.1)

A complete rewrite of the classic LootBags mod for modern Minecraft versions.

## Overview

This version of **LootBags** is a from-scratch rewrite built specifically for Minecraft 1.21.1. While it retains the core mechanics and gameplay loop of the original mod created by Malorolam, the code has been entirely reimagined to align with modern modding standards, data-driven systems, and performance optimizations.

## License

Unlike the legacy versions, this rewrite is licensed under the **MIT License** (see `LICENSE`). The mod remains open-source and easy for the community to build upon.

## Features

LootBags adds various bags to mob drop tables that, when opened, provide items from vanilla and modded loot tables.

* **Dynamic Looting:** Bags drop from mobs based on configurable loot tables.
* **Loot Recycler:** A utility block that consumes unwanted items to generate new loot bags once a value threshold is reached.
* **Bag Opener:** A block designed for automation that opens bags and outputs the contents into pipes or chests.
* **Bag Storage:** A specialized inventory for managing, storing, and converting between different tiers of bags.
* **Data-Driven:** Fully utilizes modern Minecraft's JSON-based loot table system for easy customization by modpack creators.
